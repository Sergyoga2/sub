# Hexlet Subscription Landing

Конверсионный лендинг для подписки Hexlet на каталог навыков.  
Проект собран на `Next.js 16` + `React 19` + `Tailwind CSS v4` и основан на блоках `shadcnblocks.com` с глубокой кастомизацией контента, структуры, визуала и поведения.

## 1) Цель и контекст

- Основная цель: максимальная конверсия в покупку подписки.
- Продукт: подписка на каталог из `56 навыков` (программирование, аналитика, DevOps и смежные направления).
- Язык и аудитория: русскоязычная аудитория.
- Бренд: Hexlet.
- Лендинг не копирует структуру старой страницы, а использует новую композицию блоков с акцентом на путь пользователя к тарифам.

## 2) Технологический стек

- `Next.js 16.1.6` (App Router, TypeScript)
- `React 19.2.3`
- `Tailwind CSS v4` + `tw-animate-css`
- `shadcn/ui` + блоки из `@shadcnblocks`
- `lucide-react` (иконки)
- `motion` (подключен в зависимостях)

## 3) Быстрый старт

```bash
pnpm install
pnpm dev
```

Сборка и запуск production:

```bash
pnpm build
pnpm start
```

## 4) Структура проекта

Ключевые пути:

- `app/page.tsx` — композиция всех секций лендинга в итоговом порядке.
- `app/globals.css` — глобальные переменные темы, фон, утилиты секций, анимации.
- `components/` — блоки страницы (shadcnblocks + кастомные секции).
- `components/ui/` — базовые UI-компоненты shadcn (`button`, `card`, `badge`, `separator`, `accordion` и др.).
- `public/` — локальные SVG-ассеты для Hero и CTA/feature секций.
- `components.json` — конфиг shadcn + registry `@shadcnblocks`.

## 5) Какие блоки используются

Ниже перечислены фактически используемые блоки/секции на странице.

### Блоки на базе shadcnblocks

## 6) Текущая структура лендинга (порядок секций)

`app/page.tsx`:

1. Hero (`Hero243`)
2. «Подписка позволит вам» (`Feature43`)
3. «Что мотивирует учиться дальше» (`GraduateTestimonials`)
4. «Подписка - это для прокачки» (`Feature43`)
5. Тарифы (`Pricing2`) + подсказка для оплаты картой не из РФ
6. «Как проходит обучение» (видео-блок, `LearningFormatSection`)
7. «Кому будет полезна подписка» (`Feature15`)
8. Горизонтальный CTA к тарифам (`HorizontalPricingCta`)
9. FAQ (`Faq5`)

Все CTA ведут к `#pricing` или на покупку по внешней ссылке, чтобы сократить путь до целевого действия.

## 7) Технические особенности реализации

### 7.1 Навигация к тарифам

- Hero/feature/CTA-кнопки используют якорь `#pricing`.
- В тарифах кнопки планов ведут на `https://subscription.hexlet.io/plans`.
- Добавлен отдельный payment-hint:
  - текст: «Для оплаты картой выпущенной не в РФ»
  - ссылка: `https://hexlet.io/subscription/new`

### 7.2 Блок тарифов и «рекомендуемый» план

Файл: `components/pricing2.tsx`

- Реализованы 3 тарифа: месячный, годовой, трехлетний.
- Годовой план отмечен `recommended: true`.
- Плашка «Рекомендуемый» позиционируется абсолютно и не сдвигает контент карточки.
- На годовой карточке есть одноразовая акцентная анимация (burst/confetti) при появлении секции:
  - `IntersectionObserver` отслеживает вход блока в viewport.
  - старт анимации через `1000ms` задержки.
  - анимация проигрывается один раз.

### 7.3 Видео-блок «Как проходит обучение»

Файл: `components/learning-format-section.tsx`

- Таб-переключение из 4 этапов обучения: теория, квизы, упражнения, AI-наставник.
- Источник видео: `ru.hexlet.io/vite/assets/*.mov`.
- Для визуального закрытия черных полос в роликах:
  - контейнер видео имеет `pt-[30px] pb-[30px]`
  - видео смещено `-my-[30px]` и увеличено `scale-[1.1]`
- Видео autoplay/loop/muted/playsInline для бесшовной демонстрации.

### 7.4 Глобальная визуальная система

Файл: `app/globals.css`

- Кастомные CSS-переменные брендинга:
  - primary `#2663ec`
  - hover `#3c64ff`
- Многослойный фон страницы:
  - радиальные градиенты
  - мягкий линейный градиент
  - grid-overlay (`.landing-shell::before`)
- Фоновые стили секций:
  - `.section-tint`
  - `.section-soft`
  - `.pricing-highlight`

### 7.5 Анимации и интерактив

- Reveal-анимация секций при скролле (`components/reveal-section.tsx` + `.reveal-section` CSS-классы).
- Hover-эффекты карточек и CTA (подъем, тень, контрастный hover цвет).
- CTA-кнопки унифицированы по цветам:
  - default: `#2663ec`
  - hover: `#3c64ff`

### 7.6 Адаптивность

- Mobile-first верстка на Tailwind breakpoint-утилитах.
- Точечно исправлено центрирование на мобильных:
  - метрики Hero
  - карточки тарифов (`w-full max-w-sm`, `items-center` для mobile).
- Десктопная композиция сохранена без существенных изменений.

## 8) Контент и источники

- Основной продающий copy адаптирован под подписку Hexlet.
- Видео и часть медиа-контента взяты из публичных ассетов Hexlet.
- Используются локальные SVG-иллюстрации в `public/`:
  - `hero-programming.svg`
  - `feature-format.svg`
  - `cta-zone.svg`
- В блоке отзывов используются внешние фото выпускников (URL на `ru.hexlet.io`).

## 9) Компонентная карта и ответственность

- `Hero243`: заголовок с flip-текстом, краткое УТП, social proof, первичный CTA.
- `Feature43` (x2): результат/ценность подписки в формате 6 карточек.
- `Pricing2`: оффер, 3 тарифа, recommended-бейдж, burst-анимация, payment-hint.
- `LearningFormatSection`: объяснение формата обучения через табы и видео.
- `Feature15`: сегменты ЦА, кому полезен формат.
- `HorizontalPricingCta`: дополнительный толчок к выбору тарифа.
- `Faq5`: снимает типовые возражения до покупки.
- `Cta10`: финальный призыв к действию.

## 10) Конверсионные решения, заложенные в код

- Повторяемые CTA после ключевых смысловых блоков.
- Ранняя демонстрация цены и выгод (3 тарифа, выделенный годовой план).
- Social proof:
  - бейджи в Hero
  - отзывы выпускников
- Снятие возражений:
  - FAQ-блок с условиями списаний/отмены/пробным доступом/поддержкой.
- Минимизация friction:
  - якорный скролл до тарифов
  - отдельная ссылка для оплаты картой не из РФ.

## 11) Настройка/расширение

- Добавить/изменить секции: `app/page.tsx`.
- Изменить тексты/офферы тарифов: `components/pricing2.tsx`.
- Изменить список видео/этапов обучения: `components/learning-format-section.tsx`.
- Изменить визуальный стиль и тему: `app/globals.css`.
- Подключить плавающий CTA при необходимости:
  - импортировать и вставить `FloatingPricingCta` в `app/page.tsx`.

## 12) Известные заметки

- `app/layout.tsx` сейчас с `lang="en"`; для SEO и корректной локали лучше переключить на `lang="ru"`.
- Метаданные (`title`, `description`) пока базовые и могут быть донастроены под продакшен SEO.
